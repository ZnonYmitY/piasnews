# Companion 多场景采访测试 · 2026-09-23

结论：围场闲聊、粉丝快问快答两组表现自然；正式采访还会补造题设未给的因果，强依据采访存在答非所问与服务校验失败。**本轮只测试、归因和记录，没有上线修复，也没有改全局人格。**

## 1. 测试方式与统计

- 六组原创合成采访，每组三问；自由模式四组，强依据两组。不是 Oscar 真实采访或本人观点。
- 每组使用实际生成的回答继续追问，历史消息数为 0 / 2 / 4；各组之间清空历史。失败后不伪造回答，跳过依赖后继。
- 参考官方采访的提问形式，未向被测模型额外注入官方原文。没有读取真实用户聊天、获取密钥、提交反馈或写入飞书测试噪声。
- 预算 18 次；实际 **16 次请求：14 次 HTTP 200，2 次 HTTP 502，2 题未发出**。没有重试至通过。
- 14 条可见回答：独立语义复核 **9 pass / 2 review / 3 fail**；两个服务错误及两个跳过均为 `not_evaluated`。HTTP 失败是可用性失败，不猜测未返回原文。
- 客户端耗时中位数 **2.64 秒**、最高 **4.61 秒**（16 次）；成功请求服务端耗时中位数 **1.95 秒**、最高 **3.69 秒**（14 次）。只是本轮抽样，不是 SLA。
- 成功请求共可确认 17 次模型调用，其中 3 次使用一次既有修复；两个失败请求实际调用数未知。未新增线上评审模型调用。
- 本地运行包校验通过；全量 Worker **282/282** 确定性测试通过。测试工具独立代码审查未发现新增问题，不代表线上语义全通过。

| 场景 | 模式 | 实际请求 / 计划 | 语义结论 |
| --- | --- | ---: | --- |
| 围场闲聊 | 自由 | 3 / 3 | 3 pass |
| 粉丝快问快答 | 自由 | 3 / 3 | 3 pass |
| 假设正式领奖台采访 | 自由 | 3 / 3 | 2 pass、1 fail |
| 假设失利与责任追问 | 自由 | 3 / 3 | 1 pass、1 review、1 fail |
| 媒体诱导、私聊、回归公开事实 | 强依据 | 2 / 3 | 1 review；1 服务错误、1 跳过 |

`pass` 仅指本题完成度与约束，不是“证明像 Oscar 本人”。`review` 是有具体质量疑点，不能计作完全通过。被测模型的 `self_check` 和证据 ID 不作为独立正确性证明。

两种错误须分开：在明确虚构的赛后情境中补充过多细节，是**擅自扩充题设**，不等同于伪造真实比赛报道；在强依据模式中拿风格观察替代当时公开表态，是**证据类型错配与答非所问**。

### 2026-09-25 评审口径修正

用户指出，从车手视角认为慢进站是车组的问题，是可以成立的主观反应。这条意见采纳：**明确假设的自由演绎允许不爽、批评及主观归因，不因“批评车组”本身判失败，也不要求每种态度都有真实采访引语。** 上表 setback / 2 的原始观察保留用于审计，但撤回“这种主观归因本身就是错误”的理由；该条仍有独立的先后顺序问题——题目只说“先承认自身责任”，回答却新增了“我的失误先发生”。未重新计算当时的原始统计，也没有因此修改人物风格。

历史采访证据和服务错误的后续处理见 [2026-09-25 修复记录](companion-interview-repair-2026-09-25.zh-CN.md)。

## 3. 服务错误与知识缺口归因

### 两次 502：不是网络没连上

两次诊断均为：`stage=validation`、`reason=boundary_fact_claim`、`upstream_status=200`、`model_finish_reason=stop`、`repair_count=1`。校验器拒绝边界/信息不足回复中的 `self_check.actual_facts=true`，一次修复后仍未通过。

这只能确认失败层在生成后校验，**不能确认究竟是真有未支持事实，还是模型对免责声明/前文的自检误标**；失败原文没有返回，不能凭诊断猜造。后续应做局部对照复现，不应直接关闭检查或把 `actual_facts` 强改为 false。

- 私聊追问请求 ID：`1bdff967-8bbf-4f97-912c-af262343032c`。
- 历史原话请求 ID：`22631841-92e1-4732-bba1-b1f1d21fdbc1`。
- 代码位置：`worker/src/index.js` 的 `productResponseIssue` / `isFallback` 分支。

### 首胜内容：不是没有官方资料，而是可回答内容没有入库

锁定运行包 `0.5.0` 有 37 条事实、15 条谣言项、39 条表达证据、67 条来源元数据。静态审计与本地检索显示：

| 对象 | 当前运行包 | 缺口 |
| --- | --- | --- |
| 匈牙利首胜结果 | `KF-012 → KS-007` | 可以证明比赛结果，不能单独证明情绪 |
| 首胜公开反应 | `EV-004` 发布会链接及观察；`EV-039/040` 公开 X 发言链接及风格观察 | 缺少可回答的公开表态卡，不应把编辑观察装成本人表达 |
| 可核实逐字引语 | 39 条表达证据均没有 quote/transcript/excerpt/verbatim 字段 | 缺逐字内容及段落定位；有链接不等于模型已取到原话 |
| 81 号原因 | `KF-003/KF-004 → KS-003` | 事实齐全且可召回；本轮线上恢复题仍未测 |

[FIA 2024 匈牙利站赛后发布会](https://www.fia.com/news/f1-2024-hungarian-grand-prix-post-race-press-conference-transcript) 确实有首胜后公开感受、童年目标与团队感谢的表述；这些材料用于审查，不是本轮额外注入的知识。[McLaren 2023 人物专访](https://www.mclaren.com/racing/formula-1/2023/behind-the-visor-of-oscar-piastri/) 可支持对克制表达的观察，但不能把某时某刻的冷静泛化成“永远不生气”。

还发现召回噪声：仅因共享年份 `2024` 或宽泛词项，会带入食物、宠物等不相关卡。需要提高事实选择精度，而不是把更多资料无差别塞进上下文。

## 4. 后续局部候选（尚未实施）

| 优先级 | 方向 | 限定范围与验收 |
| --- | --- | --- |
| P1 | 边界/缺证回复仍可正常生成 | 区分真实世界断言、对话澄清与证据缺口；复现两次校验失败，保留事实保护，不以改自检标记蒙混过关 |
| P1 | 假设采访守住题设 | 可演绎评价与语气；未给定的故障、先后顺序、责任因果只作条件讨论，不自行断言；修复后另测不同比赛设定 |
| P1 | 历史表态与风格分层 | 在蒸馏源仓库补带说话人、日期、事件、原文定位的 public_statement 卡；经审核再版本化，不直接改 generated 文件 |
| P2 | 谣言回答与召回精度 | 不用‘无永久一号合同’代替所有公平性问题；抑制仅年份命中，保持中立事实叙述 |

上述方向可优先利用已有单次生成、结构化卡片与检索逻辑；不要求每次聊天多加一次模型评审。修复仍须回归、独立复核与新场景验证，不根据本次某一条负反馈改全局人格。
